# 行为验收

`behavior-cases.json` 是人工/宿主会话验收场景，**不由 `npm test` 当作模型测试执行**。

在目标宿主的新会话中载入待测版本，给出场景的用户请求和必要输入。对自动触发场景先不显式指定 Skill；对手动 Skill 显式调用。记录所用宿主、模型、集合版本/提交、实际激活的 Skill、输出和各项期望是否满足。不要只检查输出包含关键词。

优先覆盖本次改变的能力；发现失败后先修正，再复测相关场景。发布时在 PR 中列出实际跑过的场景和未覆盖范围。脚本/资源烟测只能证明结构和安装行为，不能证明教学、设计判断、制图美感或所有视频站点成功。

当前新增用例是待执行的行为验收集，不附虚构的通过记录。现有 `grill-with-docs` 是组合 Skill，需同时安装 `grilling` 和 `domain-modeling`。
